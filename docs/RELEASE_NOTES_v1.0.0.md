# Tools3000 v1.0.0 官方正式版发布说明 (Official Release Notes)

欢迎体验 **Tools3000 v1.0.0 正式版**！这是 Tools3000 历经深度打磨与系统架构精细演进后的首个官方正式里程碑版本。

Tools3000 是一款专为 Windows 平台日常办公、设计创作、开发运维与极客生产力打造的**全场景高性能原生桌面效率工具箱**。通过原生 C++20 微内核与全链路 GPU 硬件加速渲染，Tools3000 将**文件搜索、鼠标手势、触发角、截图与录屏、按键回显、鼠标演示与特效、文件对话框助手、远程协助增强**深度融为一体。旨在为每一位用户提供流畅自如、轻盈纯净、无打扰的极致桌面体验。

Welcome to **Tools3000 v1.0.0 Official Release**! This is the first official milestone release of Tools3000. Engineered with a native C++20 microkernel alongside GPU-accelerated rendering and WebView2 decoupling, Tools3000 integrates **File Search, Mouse Gestures, Hot Corners, Screen Capture & Recording, Keycast Overlay, Cursor Effects & Presentation, File Dialog Enhancer, and Remote Assistance Boost** into a rock-solid, ultra-lightweight productivity suite.

## 🌟 核心功能深度解构（按客户端核心功能导航顺序）

### 1. ⚡ 文件搜索 (File Search) — 眨眼之间，全盘文件与深度正文秒出
- **场景与痛点**：在赶写方案或开会时要找一份半年前的文件，Windows 自带搜索转圈半天还经常搜不到，急死人。
- **用户体感与实际解法**：
  - 任何时候随手按下 `Alt + Space`，搜索浮窗 0 延迟弹出；
  - 打字不用切中文输入法，支持拼音首字母盲搜——随手敲 `xshz`，几百万个文件里半年前存的《销售汇总.xlsx》0.01 秒直接跳在第一行，回车即开；
  - 支持直接穿透搜索 Word、Excel、PPT、PDF、纯文本乃至代码里的正文内容；
  - 搜到文件轻敲空格键即可大图预览排版或语法高亮，不用花十几秒苦等大型办公软件启动；
  - 按需常驻契约（`DEMAND_START`）：平时不读盘、不占 CPU，仅呼出时按需工作，按 `Esc` 瞬间熔断释放。

### 2. 🖱️ 鼠标手势 (Mouse Gestures) — 随手一划，桌面掌控行云流水
- **场景与痛点**：每天查资料、看几十页网页，手腕要频繁把鼠标大幅甩到屏幕左上角点“后退”或找小小的“×”关闭标签，一天下来手腕酸痛。
- **用户体感与实际解法**：
  - 在屏幕任意地方按住鼠标右键轻轻一划：向下向右划“L”直接关闭当前网页或窗口，向左划后退，向右划前进，向下划最小化当前窗口；
  - 在桌面或任务栏上按住右键滚轮轻轻一滑，直接无缝切换 Windows 虚拟桌面或平滑调节音量，连控制面板都不用点；
  - 内置独创抗手抖容错算法：哪怕随手一挥画得歪歪扭扭也能 100% 精准识别意图，彩色轨迹细腻圆润，随手划动如行云流水。

### 3. 🖥️ 触发角 (Hot Corners) — 随手盲甩，屏幕四角直达桌面与锁屏
- **场景与痛点**：多窗口堆叠如山时想看一眼桌面文件，得小心翼翼找任务栏最右下角那条细线；离开工位想锁屏防窥，双手得在键盘上摸索快捷键。
- **用户体感与实际解法**：
  - 将光标随手甩向屏幕四个物理角落，零思考秒级激活预设动作；
  - 甩到右上角瞬间返回清爽桌面，甩到左下角一秒息屏锁屏保护隐私，甩到左上角展开多任务视图；
  - 智能防抖防误触滤波，只有真正主动推入角落才会触发，日常大幅移动光标路过绝不误触。

### 4. 📸 截图与录屏 (Screen Capture & Recording) — 零黑屏标注与防盲录高清动图
- **场景与痛点**：截图慢、卡顿黑屏；标注步骤删掉一个序号就全乱了；录屏不知道边框在哪，或者意外关机导致录了一小时的视频全部损坏。
- **用户体感与实际解法**：
  - **毫秒截图标注**：按下快捷键瞬间零黑屏定格，自动智能磁吸窗口并剔除黑边；配备平滑手绘笔、透亮荧光笔、高斯模糊马赛克；神级“自愈序号”即使中间删掉一步也会自动重新连续编号；
  - **置顶贴图与离线 OCR**：设计对照或查代码时一键把截图钉在屏幕顶层（支持缩放与透明调节）；右键点击“提取文本”，瞬间离线提取文字复制到剪贴板，断网也能秒识别；超长网页支持一键滚动长截图自动拼接；
  - **防盲录高清录屏**：选区后桌面呈现清爽的镂空呼吸发光框，清清楚楚知道录像边界，彻底告别盲录焦虑；悬浮工具条贴边避让不挡画面；鼠标点击散发平滑水波圈；
  - **断电不损坏与高清动图**：工业级分片安全封装，录制中途电脑断电或崩溃视频文件依然完好可播放；一键生成色彩细腻饱满、无色彩噪点的高清 GIF 动图，随手发群沟通。

### 5. ⌨️ 键盘按键回显 (Keycast) — 优雅浮现，教学演示与按键神器
- **场景与痛点**：做软件教学视频、投屏演示时，学员总是问“刚才按了什么快捷键”；而传统按键回显软件打字时满屏狂飞字母，打扰视线。
- **用户体感与实际解法**：
  - 录课或开会演示时，按下快捷键会自动在屏幕角落以极具质感的半透明微晶磨砂键帽优雅呈现（如 `Ctrl + C`，连续按还会显示 `×3` 连击计数）；
  - 上档键智能折叠：按 `Shift + 8` 自动简练折叠为单个标准 `*` 键帽，清爽不拖沓；
  - 最懂人性的智能打字静默：平时正常写长篇方案敲字时它完全安静隐退；只有当你按下功能快捷键时才优雅浮现；
  - 100% 本地运算，所有击键统计与热力图纯本地存储，绝不泄露任何输入隐私。

### 6. 🪄 鼠标演示与特效 (Cursor Effects & Presentation) — 会议演示全场焦点利器
- **场景与痛点**：在投影大屏演讲或线上会议屏幕共享时，内容太多太杂，听众经常眯着眼找不到鼠标光标到底指在哪里。
- **用户体感与实际解法**：
  - 重点讲解时，只需【快速双击两下 Ctrl 键】，周围屏幕瞬间柔和变暗，一道明亮柔和的聚光灯光圈紧紧跟随着鼠标移动，全场视线瞬间聚集到核心焦点；
  - 鼠标拖拽带出唯美的流光粒子尾迹；左键点击散发蓝色水波圈，右键点击散发翡翠绿水波圈，点击动作清清楚楚；
  - 演示完毕晃动鼠标或按 Esc 瞬间淡出还原，且底层几何避让全屏检测，绝不误触发系统的专注助手（免打扰）。

### 7. 📁 文件对话框助手 (File Dialog Enhancer) — 彻底消除深层目录翻找痛点
- **场景与痛点**：在浏览器保存图片，或者在 Word/PS 里打开文件，弹出来的往往是上一个不知道哪里的旧目录，而旁边资源管理器明明已经打开了目标文件夹，却得一层层点开或复制路径粘贴，极为繁琐。
- **用户体感与实际解法**：
  - 独立应用路径记忆：VS Code 记住工程路径，浏览器记住素材路径，互不串台干扰；
  - 一键秒切当前文件夹：文件弹窗顶部自动悬浮半透明微晶胶囊条，点一下即可瞬间跳转到你当前正在浏览的资源管理器文件夹所在路径，告别重复翻找。

### 8. 🌐 远程协助增强 (Remote Assistance Boost) — 远程办公沉浸穿透与按键急救
- **场景与痛点**：居家远程办公用向日葵、ToDesk、mstsc 连公司电脑，想按 `Alt+Tab` 切窗口却切到了本机桌面；更要命的是网络一抖动，远端的 `Ctrl` 或 `Alt` 经常粘滞卡死，打字全是快捷键关窗口。
- **用户体感与实际解法**：
  - 系统快捷键全穿透：在远程窗口里按下 `Alt + Tab`、`Win + E`、`Win + R` 等系统组合键，100% 直通远端机器执行，绝不被本机系统截胡夺焦，如同端坐在远端电脑前；
  - 修饰键粘滞卡死一键急救：网络卡顿时一旦遇到按键粘滞卡死，只需【快速双击右侧 Ctrl 键】（或按全局急救键 `Ctrl + Alt + Backspace`），瞬间彻底冲刷释放所有卡住的键，原地秒级复活；
  - 输入法智能脱敏：光标移入远程窗口自动切为英文键盘（`ENG 0409`），避免在远端 Linux 终端敲命令时被中文拼音打断，移回本机无感恢复中文输入。

## 📊 物理内存占用横向对比 (Memory Consumption Benchmark)

Tools3000 依托现代 C++20 原生微内核与冷路径物理工作集修剪机制（`trimWorkingSet`），彻底颠覆了“功能多就必定臃肿吃内存”的固有印象：

```
物理内存常驻占用对比 (越小越轻快)：
┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔴 典型 Electron 类桌面工具 (300 MB ~ 800 MB)                              │
│    ██████████████████████████████████████████████████████████ 600 MB (典型值)│
├─────────────────────────────────────────────────────────────────────────────┤
│ 🟡 传统 C# / .NET 桌面工具 (120 MB ~ 200 MB)                               │
│    ████████████████ 160 MB                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 🟢 Tools3000 全功能高频运转 (全功能全插件并发常驻仅 20 MB ~ 40 MB)          │
│    ███ 28 MB                                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ ⚡ Tools3000 日常托盘静默待机 (仅 ~11 MB 物理内存，待机 CPU 恒为 0.0%)     │
│    █ 11 MB                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **日常静默待机仅 ~11 MB**：原生编译无任何庞大虚拟机包袱，闲置时 WebView2 自动挂载 `TrySuspend()` 冻结 JS 堆；
- **全功能运转仅 20~40 MB**：全部 8 大核心功能与插件并发常驻仅占传统 Electron 工具的 1/20；
- **任务退场 0.5 秒极速收缩**：截图完成、录屏封装结束、长截图拼接与 OCR 识别完成后，系统自动执行冷路径物理内存修剪，将临时显存与数据缓冲区毫秒级交还给操作系统。

## 🏗️ 极客硬核技术栈与微内核架构解析

面向开发者与极客，Tools3000 严格践行高内聚、低耦合的世界级系统工程标准：

1. **现代 C++20 原生系统级内核**：全代码库基于 C++20 原生编译，享受强类型约束与零运行时开销，彻底杜绝托管语言垃圾回收（GC）引起的卡顿、丢字与帧率抖动；
2. **底层 Win32 输入路由与加速器管线**：挂载 `KeyboardPipeline` 拦截 `SC_KEYMENU` 与 `WM_HELP`，屏蔽 Chromium 默认浏览器冲突快捷键，实现全链路纳秒级输入分发；
3. **GPU 硬件加速渲染矩阵**：DirectComposition、Direct2D、DirectWrite 与 Direct3D 11 全链路硬件合成；手势采用局部 100~300px 最小包围盒微视口，点击水波纹使用 256 阶查找表（LUT）0-sqrt 优化，渲染丢帧率 0.00%；
4. **WebView2 现代渲染解耦与自动休眠**：配置中心采用 React 19 + TypeScript 现代前端栈，通过 C++ 高性能内存管道双向通信；窗口隐藏或闲置 60 秒后自动回收渲染子进程，兼备界面高颜值与底层极致速度；
5. **微内核插件化拓扑**：主程序与各个功能模块严格遵循物理隔离，全部拆解为独立的 C++ 动态链接库（`Plugin_*.dll`），由 `Tools3000Core` 核心事件总线统筹调度；
6. **可信本地 Lua 自动化扩展**：内置轻量级 Lua 引擎作为宿主授权的可信本地扩展通道，支持编写自定义脚本联动系统 API 与桌面自动化能力；
7. **x64 与 ARM64 双架构原生支持**：从底层汇编到构建脚本全部保持多架构便携性，原生适配 Intel/AMD x64 处理器与 Surface Pro / 高通骁龙 Windows on ARM 设备。
