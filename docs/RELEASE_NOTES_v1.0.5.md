# Tools3000 v1.0.5 官方正式版发布说明

欢迎使用 **Tools3000 v1.0.5** 官方正式版。以下为本次版本的核心功能演进、问题修复与底层架构改进摘要。

---

## 本次重点更新与体验改进

### 业务与功能体验进化 (用户视角)
- 选中文字原位智能批注：贴图与截图框选双入口支持对识别出的文字一键添加清透荧光笔、38度斜角书法丝带波浪线与微弧手绘重点直线，支持同选区叠加、快捷键极速落笔、多色实时换色与无损撤销重做，且零重跑 OCR
- 批注工具栏视觉重构：贴图悬浮舱与截图二级属性栏全面升级为高定微晶分段轨道槽、立体浮起滑块卡片与高光珠宝色珠，彻底消除廉价红底误配与拥挤观感
- 录屏防绿屏与灵活输出：点击结束瞬间截断采集彻底杜绝等待界面混入与末尾草绿屏；新增录屏准备栏「原样直出（跳过演播室）」、演播室顶栏「原样模式」一键切换及全偏好永久记忆
- 演播室未导出防丢保护：尚未导出成片即关闭演播室时弹出高定微晶确认框，明确提供「保存后退出」（无修饰时 0 秒无损直存原片，有修饰时自动导出后关闭）与「不保存退出」（自动清理临时录像母带）
- F3 贴图防重复与跨虚拟桌面隔离：连续按 F3 智能跳过已在当前虚拟桌面显示的贴图不再反复套娃，全部已在桌面时直接聚焦并提示；在空白虚拟桌面截图时不再误识别其他虚拟桌面的隐藏窗口
- OCR 结果对照窗关闭体验修复：彻底根治点击右下角「关闭」与按钮无响应的致命问题，新增标题栏右上角矢量关闭键，无选区单按 Esc 即刻关闭。

### 架构演进与技术重构 (底层实现)
- 新增 TextAnnotationHelper.h 实现版面感知跨行选区桥接、黄金呼吸间距基线与 C无穷光滑相位调制的 38 度斜角平头书法笔尖丝带生成器，结合 MarkupEngine 单通道联合蒙版正片叠底与背景亮度自适应油墨渐变
- ScreenRecorder 引入微秒级 freezeCaptureImmediately 物理采样屏障、RecordingIndicator 轻量保存态接管、StudioPreviewWindow 离屏首帧预提交与 AVFrame TV Black 预填四重防线
- PinPasteCoordinator 引入 64-bit 网格采样内容指纹 computeContentFingerprint 与当前桌面活跃贴图去重；WinUtils 新增基于 DWMWA_CLOAKED 与线程局部 IVirtualDesktopManager 的跨虚拟桌面窗口权威判活
- 定位并修复 OcrResultWindow 在 WM_LBUTTONUP 中先调 ReleaseCapture 同步触发 WM_CAPTURECHANGED 清空按压态的深层 Win32 缺陷及二次刷新 m_currentAlpha=1.0f 幽灵窗问题，将其正式纳入 Tools3000Tests 单元测试
- StudioPreviewWindow 新增原样配置判定、未导出编辑检测与 Direct2D 微晶防丢确认模态框，并补齐左侧抽屉控件实时 ConfigManager 持久化及配套防回退回归测试。
