# Tools3000 v1.3.0 官方正式版发布说明

欢迎使用 **Tools3000 v1.3.0** 官方正式版。以下为相较上一个正式发行版 **v1.2.1** 的核心新功能、社区反馈落地与性能优化摘要。

---

## 新功能与重点升级

### 1. 全新独立 Rust 版 Picasa 轻量看图器 (`Tools3000_Picasa_Viewer.exe`)
- **单文件零依赖与原版灵魂还原**：基于纯 Rust + Direct3D11 / DirectComposition / Direct2D 构建，体积 `< 2 MB`、无需额外运行库即可独立运行；完整还原半透明桌面穿透、纯净贴边柔和阴影、图片区内左键自由拖拽定位、点击空白处或任务栏自动缩为标准可缩放小窗口、光标锚点对数滚轮缩放、底部胶片缩略图流、平滑叠化幻灯片放映与两级 `Esc` 退出，并实现 GPU 上传后零双份常驻与空闲极低内存占用。
- **现代高分屏与格式补强**：原生适配 100%~250%+ 混合多屏缩放，支持 17 种常见/现代/动图/矢量图片格式与顺逆时针旋转、水平/垂直无损翻转；内嵌与主程序一致的 8 语种并自动跟随系统语言，内置高分屏文件关联配置面板（安装包默认不勾选，可随时在「设置 -> Picasa 看图器」一键开启或关闭）。

### 2. 文件与全文搜索全面重构
- **独立标准 Windows 应用窗口**：支持任务栏驻留、最小化、最大化/还原、系统分屏贴靠与右键窗口菜单，切到其他软件后按 `Alt+Space` 直接呼出搜索窗，不再误触发上一次结果的快速预览（感谢 V2EX `@xclimbing`）。
- **Everything 风格纯净表格视图与扩展属性列**：升级为高密度表格视图，全列支持表头整格点击直控排序、自由调宽、拖拽换序与右键选列；支持 36+ 扩展属性视口惰性加载、随时可选历史搜索下拉与底部实时扫描进度栏（感谢 V2EX `@xclimbing`）。
- **跨层级斜杠拼音与通配符路径搜索**：原生支持 `gzml\user`、`*gzml*\*user*`、`parent:gzml\user` 等中文路径首字母/全拼混合检索并同步补全至 `F1` 语法速查与设置页手册；补齐 3,689 字全拼表并保持低内存驻留，海外非中文环境默认关闭拼音避免误匹配（感谢 V2EX `@xclimbing`）。
- **全文内容搜索防失控保护**：为 `content:` 全文检索新增窗口切至后台自动暂停、隐藏即停、后台 I/O 降权以及 20 秒 / 3 万文档软熔断与「继续深扫」断点续扫，避免无人值守扫盘拖慢整机。

### 3. 截图独立快速保存与 OCR 识别提速
- **截图工具栏新增独立「快速保存」按钮**：左键点击或按 `Ctrl+Shift+S` 免弹窗一键直存截图保存目录（默认 `%LOCALAPPDATA%\Tools3000\Screenshots`，便携模式为程序同级 `Tools3000Data\Screenshots`，可在「设置 -> 截图与录屏 -> 保存目录」随时自定义并常驻展示，无需开启自动保存），右键点击或按 `Ctrl+S` 弹出系统另存为对话框，完整覆盖普通截图、长截图与贴图二次编辑（感谢 V2EX `@wildqueen`）。
- **OCR 识别大幅提速**：修复同目录误清 DirectML 推理会话导致的重复冷启动，引入两阶段热保活（60 秒显存整理 + 15 分钟空闲释放）、4KB 模型头校验与二维码局部 ROI 快路径，大幅缩短截图与贴图文字识别耗时。

### 4. 鼠标手势个性开关与硬件亮度控制
- **轨迹视觉独立开关**：新增「松手渐隐效果」与「手势提示文字」独立开关，关闭渐隐后松手 0ms 即刻清屏，轨迹线与提示文字可自由正交组合（感谢 V2EX `@wildqueen`）。
- **原生删除键与单键快捷发送**：内置命令新增「删除键 (`Delete`)」「退格键 (`Backspace`)」，手势「发送快捷键」编辑器放行单键录入，无需手写 Lua 脚本（感谢 V2EX `@wildqueen`）。
- **鼠标滚轮屏幕边缘调节真实硬件亮度**：内置命令新增「调高/调低屏幕亮度」（支持屏幕边缘滚轮预设），自动识别外接显示器（DDC/CI）与笔记本内置屏（WMI），按光标所在屏幕独立调光并弹出实时百分比 OSD（感谢 V2EX `@wildqueen`）。

### 5. 后台待机瘦身与发布包精简
- **后台静默资源治理**：完善 WebView2 隐藏挂起与 QuickLook 闲置销毁、截图插件 12 个重型多媒体/AI 运行库按需延迟加载、贴图写时复制及 AI 修复/聚光灯闲置释放，显著降低后台常驻内存与 CPU 唤醒，同时保持高压下手势跟手与搜索瞬开。
- **安装包瘦身与文档同步**：剔除冗余未引用 DLL，跨账户卸载自动清理注册表与文件关联，发布资产精简为清爽 3 件套（安装包、便携包、`SHA256SUMS.txt`）；更新「关于」页面核心技术栈与全部 8 语种 README。
