# Tools3000 v1.3.1 官方正式版发布说明

欢迎使用 **Tools3000 v1.3.1** 官方正式版。以下为相较上一个正式发行版 **v1.3.0** 的鼠标手势核心体验升级、社区反馈落地与稳定性修复摘要。

---

## 本次重点更新与体验改进

### 1. 新增「手势图形匹配阈值」与圆弧手势识别增强
- **可调「手势图形匹配阈值」设置**：在「设置 -> 鼠标手势」新增图形匹配阈值调节（`50%–100%`，默认 `75%`；设为 `100%` 时切换为严格精确方向匹配），兼顾自然圆滑手写与精准控场需求 (#4, @Yafeiml)。
- **反 C / 正 C 等平滑圆弧识别率大幅提升**：重构方向段化简与 32 点折线/圆弧双原型方向敏感相似度引擎，修复反 C（`→ ↓ ←`）、正 C（`← ↓ →`）、U 形等手势因平滑弯曲或收笔微斜导致的识别失败，同时完整保留「下右（`↓ →`）」收笔防误触保护 (#4, @Yafeiml)。
- **严防多段误触单段**：形状相似度兜底引入拓扑护栏与起止端头切向一致性校验，杜绝未命中的多段或圆弧轨迹降维误触发单段直线手势（如最小化、后退、前进）。

### 2. 普通右键单击零起始光点闪烁
- **轨迹覆盖层对齐最小识别距离延迟激活**：按下右键但移动未超过「手势最小识别距离」（默认 `24px`）前全程零光点、零覆盖层唤醒，普通右键点击更干净利落；跨过阈值后无缝回填起笔及途经轨迹，并同步优化原地按住右键滚轮时的动作提示展示 (#4, @Yafeiml)。

### 3. 自定义录制画板重构与 V 形对角手势精准识别
- **前后端识别算法同源对齐与尖角消歧**：重构前端录制画板识别管线使其与原生 C++ 引擎 100% 一致，新增上下文尖角矢量消歧、8 方向对角抖动消除与圆底折叠，随手绘制各种自然倾角的 V 形（`↘ ↗`）等对角手势均可稳定一次录准（感谢小众软件 @buliugu）。
- **新增手动 8 方向箭头点选拼装与实时预览**：画板下方新增 8 方向矢量箭头点选拼装条与退格按钮（点选 `↘` + `↗` 即可秒建 V 形手势），绘制过程实时展示识别箭头徽章，快捷预设同步补充「反 C（`→ ↓ ←`）」与「V 形（`↘ ↗`）」（感谢小众软件 @buliugu）。
- **修复对角手势前缀冲突误报**：前缀冲突检测升级为段级严格匹配，修复新建 `↘ ↗` 等对角手势时误报与 `↓` 冲突的问题（感谢小众软件 @buliugu）。

### 4. 高速连续手势防误触与稳定性加固
- **高速连划「下右」关闭标签页防误触优化**：解耦「起笔激活距离」与「拐弯切段距离」，并增加高速连划起笔短暂复位惯性容错，大幅提升连续快速画 `↓ →` 关闭多个浏览器标签页时的命中率，减少误触「最小化」。
- **取消单段对角隐式跨手势展开**：不再将单段斜拉（如 `↙`）静默展开为组合手势（如 `↓ ←` 关闭窗口），避免斜拉早松手误关整个浏览器窗口。
- **配置持久化、并发安全与诊断日志补强**：修复历史遗留配置键重启覆盖「最小识别距离」、设置页触发键更新接口错误及渲染线程弱内存序隐患，并新增轻量结构化手势诊断日志便于快速排查手感问题。

### 5. 搜索结果表格「所在目录」列宽自由拖拽修复
- **全列 1:1 像素级顺滑调宽**：修复默认表格视图下拖动「所在目录」右边界误压缩右侧「大小」列而被 `72px` 最小宽度卡死、以及锁宽后仍被 `minmax(px, 1fr)` 强行撑回导致缩不动的问题；改为与 Windows 资源管理器 / Everything 一致的单列像素直调，拖动时自动冻结左侧弹性列防漂移，超出窗口宽度自动触发平滑横向滚动（感谢 V2EX @lzrainchen）。
