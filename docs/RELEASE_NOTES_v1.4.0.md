# Tools3000 v1.4.0 官方正式版发布说明

欢迎使用 **Tools3000 v1.4.0** 官方正式版。本版本为相较 **v1.3.2** 的重磅功能演进版本，全面落地社区高票呼声的**截图原位翻译**、**纯 Rust 持久化剪贴板管理**、**全盘文件/正文搜索 CLI 与 MCP Server**、**全局搜索浏览器书签直达**、**文件搜索体验升级**以及 **Windows 10 兼容加固与版本自动更新**。

---

## 本次核心新增与体验升级

### 1. 微信级截图原位翻译（免 Key 开箱即用 + 自定义大模型 / BYOK）
- **截图即译、原位覆盖、0ms 原/译瞬切**：在 `F1` 截图工具栏与 `F3` 贴图新增「翻译」入口，复用离线 OCR 版面分析自动合并自然段落，在原图文字位置以 1:1 原生字形无拉伸渲染译文，非破坏保留原图底稿支持原/译瞬间切换（感谢 Linux.do @wei_gao、@kkv、@calg）。
- **免 Key 双通道 + 灵活 BYOK**：默认提供零配置免费双通道（优先国内直连，并发批量翻译配会话缓存与超时熔断），同时支持接入 OpenAI 兼容接口 / DeepSeek / Gemini / 本地 Ollama / DeepL，API Key 经 Windows DPAPI 本机加密存储。
- **代码语义防火墙与清晰排版**：自动保护 JSON 键名、模板插值、驼峰/下划线代码标识符、路径及常见技术缩写不被误译；自动识别边框与视觉分隔墙保持精准左对齐，设置中心对应菜单统一整合为「文本识别与翻译」。

### 2. 纯 Rust 内核持久化剪贴板历史管理 (`Alt + V`)
- **关机重启持久保留与托盘一键直达**：自研零外部依赖纯 Rust 原子二进制持久化引擎（`history.t3k` + 校验和与自动备份回退 + 孤儿文件 GC），彻底解决系统自带 `Win + V` 关机即清空历史的痛点；支持 `Alt + V` 全局秒呼与系统托盘右键菜单一键打开，并内置图片优先捕获、哈希去重、隐私格式与密码管理器进程自动避让（感谢 Linux.do @wei_gao、@calg）。
- **桌面级批量多选与进阶效率**：
  - 支持 `Shift + 点击` 固定锚点连选/回缩、`Ctrl + 点击` 逐条加选/反选、`Ctrl + Shift + 点击` 追加区间、`Ctrl + A` 全选、`Shift + ↑/↓` 键盘扩缩与 `Space` 快速勾选；
  - 支持**按勾选顺序合并粘贴**（换行 / 空行 / 空格分隔）、一键**批量删除**与**批量归组**；
  - 完整保留 **HTML / RTF 富文本样式**（惰性按需加载零列表载荷，`Shift + Enter` 随时剥离为纯文本）、**自定义收藏分组**、纯文本详情区**一键内联编辑**、**`Alt + 1..9` 秒贴前 9 条**，以及图片条目一键联动 `F3` 贴图 / 离线 OCR / 原位翻译。
- **完整原生桌面窗体操纵**：支持全区拖动、8 向边缘拉伸、原生最大化/还原与 Aero Tear-Off 脱离还原、自定义位置尺寸记忆及「置顶固定」模式。

### 3. 全盘文件与正文搜索 CLI + MCP Server（赋能 AI Agent 接入）
- **单文件极简零依赖 (`tools3000-cli.exe`)**：纯标准库 Rust 编译（约 `350 KB`），零额外运行库依赖，毫秒级直连本机 Tools3000 搜索索引执行文件名与文档正文检索，并内置标准 **MCP (`stdio`) Server** 供各类 AI Coding / Desktop Agent 一键接入（感谢 Linux.do @windmill）。
- **默认关闭与零侵入安全边界**：严格遵循 `DEMAND_START`（查询状态与 MCP 握手绝不唤醒后台服务）、默认关闭外部接口总开关（需在设置中心手动启用）、强制只读并内置双层敏感凭证路径黑名单（`.ssh`、`.aws`、`.env`、私钥与浏览器凭据库）。

### 4. 全局极速搜索 (`Alt + Space`) 体验跃升
- **零冲突直搜浏览器书签 (`bm:`)**：支持自动索引本机 Edge / Chrome / Brave / Vivaldi / Chromium 书签（零常驻线程、按文件变更节流懒加载），提供 `bm:` 专用前缀、独立「书签」分类胶囊及可开关的常规搜索混排，回车直开默认浏览器（感谢 Linux.do @thinkhard）。
- **默认新增「打开次数」列**：表格视图按对象标识、量化指标、时间维度升级为默认 6 列（`名称 / 路径 / 大小 / 打开次数 / 修改时间 / 创建时间`），打开文件后计数即时 `+1`，且老用户配置无损平滑迁移（独立列开启时自动去重文件名内重复徽标）。
- **自定义分类栏拖拽排序**：顶部分类栏左侧固定「全部 / 文档内容」，右侧 `文档 / 图片 / 视频 / 音频 / 压缩包 / 代码 / 文件夹 / 书签` 均支持自由拖拽排位并跨重启永久记忆，右键可一键恢复默认顺序，`Tab` 轮切与 `Alt + 1..9` 快捷键实时同步自定义顺序。

### 5. 贴图、截图、自动更新与平台安全加固
- **贴图 120Hz 无级丝滑缩放**：`F3` 贴图滚轮升级为对数空间指数阻尼动画与光标锚点无级缩放，动态缩放零掉帧、落定自动锐化高清采样。
- **F1 智能捕获窗口稳态升级**：大幅降低同窗口微移时的选框抖动，屏蔽隐形阴影与窗外幽灵层，显著减少交叉控件误框。
- **版本更新红点提醒与自动下载安装**：检测到新版本时托盘图标动态合成红点角标、侧边栏与托盘弹窗联动提示，支持后台流式下载、SHA-256 字节级强校验与一键静默升级。
- **Windows 10 兼容加固与供应链清零**：兼容 Windows 10 旧版深色边框属性与 DWM 降级逻辑，缺失 WebView2 Runtime 时弹出 8 语种友好引导直达微软官方安装页（感谢 Linux.do @siryu）；同步清零 GitHub Dependabot 全部前端依赖告警（`npm audit` 达 `0 vulnerabilities`）。
