# Tools3000 v1.4.2 官方正式版发布说明

欢迎使用 **Tools3000 v1.4.2** 官方正式版。本版本基于 **v1.4.1** 围绕社区高频反馈与实机体验进行了全面升级：让文件搜索一步直达软件、系统工具与带原站图标的书签，新增对话框内嵌搜索、右键一键解锁被占用文件、全 8 语种自动离线识字与无痕原位翻译、手势停顿自动取消与多开切窗、空格直看压缩包/字体/音视频，并彻底修复剪贴板白屏、管理员模式下打开浏览器卡死以及含中文等非英文安装目录无法加载插件的问题。

---

## 本次重点新功能与体验升级

### 1. 文件搜索（`Alt + Space`）更像你的桌面万能启动器
- **统一搜软件、系统工具与原站图标书签**：除秒搜全盘文件外，现在也能直接搜出已安装的桌面/商店应用（支持 `app:` 前缀）以及 37 个常用 Windows 系统工具（如输入 `cmd:env` 直达环境变量），并支持 `b:` / `bm:` 前缀直搜 Edge / Chrome / Brave / Vivaldi 浏览器书签（感谢 Linux.do @wei_gao、@thinkhard）。
- **「Windows 图标」模式下真实原图标全覆盖**：开启「Windows 图标」风格后，搜索结果里的软件、系统命令和浏览器书签都会直接显示原本的真实图标（例如 Chrome、知乎等网站原本的图标直接读取本地浏览器缓存，全程离线不联网）。
- **搜索窗口实时显示最新变动文件**：开着搜索窗时，新建、下载或改名的文件会实时自动出现在结果里，不用反复关闭重搜；支持在设置页或搜索窗底部状态栏一键开关。
- **搜索后台内存 3 档自由掌控**：在设置页新增「全驻留 / 空闲释放 / 空闲休眠（0 MB）」三种内存模式，并可直观查看当前内存占用或手动一键释放/休眠，低配办公本用完也能彻底省下内存（感谢 Linux.do @longqiuyu）。

### 2. 打开 / 保存文件弹窗也能像 Listary 一样直接搜目录
- **弹窗内嵌即搜即跳**：在 Windows 的「打开 / 另存为 / 选择文件夹」弹窗上方快捷栏里，直接输入关键词就能秒搜文件夹并一键跳转过去，告别一层层手动翻目录（感谢 Linux.do @wei_gao）。
- **另存为文件名绝对安全**：在「另存为」窗口里跳转目录时，底部已经填好的文件名会被严格保护、绝不被覆盖。
- **软件自身弹窗同样支持**：Tools3000 自己弹出的文件选择框（如「问题反馈 -> 附带截图」）现在也能直接用上快捷跳转与内嵌搜索。

### 3. 新增「文件占用解锁」：删不掉文件时一键找出谁在占用
- **三种顺手入口、平时零内存常驻**：在文件或文件夹上右键点击「查看文件占用 / 解锁」（支持设置为按住 `Shift + 右键` 才显示，保持右键菜单清爽）、在搜索结果上右键、或在设置中心专门的「文件占用解锁」页面直接选择文件/文件夹，都能秒查占用进程并一键安全释放文件锁（感谢 Linux.do @ckcat）。
- **托盘控制中心一键开关**：在系统托盘右键弹出的快捷面板里，同步补齐了 **「剪贴板」** 与 **「文件解锁」** 的一键启停开关，常用工具抬手就能控制。

### 4. 8 国语言截图自动离线识字 & 原位翻译观感全面升级
- **截取外语图不用手动切语言**：无论界面是什么语言，截取日语、韩语、俄语、西班牙语或葡萄牙语图片时，离线 OCR 都会自动识别语种并顺畅衔接原位翻译；16 MB 基础中/英包保持极速零负担，日/韩/俄/西葡 4 套轻量语言包可在设置页按需一键下载；贴图右键「文字划选与翻译 -> 识字语种」也支持对单张图直接指定语言重识。
- **原位翻译更干净、排版更贴合原图**：大幅优化深色界面、新闻网页与密集表格的擦除和排版效果，消除原文字残留毛边、居中跑偏、大标题变细以及深色小字发白刺眼的问题。

### 5. 鼠标手势更好用：防误触、切已有窗口不重复多开
- **划动中途停顿自动取消默认开启**：按住右键划了一半后悔时，稍微停顿一下（默认 0.7 秒，可自行调整）手势就会自动取消，大幅减少误触发（感谢 Linux.do @sakura_yae）。
- **运行程序智能切回已有窗口**：手势动作「运行程序」新增运行模式，默认优先切回已经打开的窗口而不是傻傻重复多开；即使像 Chrome 一样带了不同 `--user-data-dir` 参数开了多个独立窗口，也能精准切回对应的那一个。老手势只需点开编辑弹窗下方的「高级执行特性」确认一下运行模式即可（感谢 Linux.do @sakura_yae）。
- **保留好玩的小彩蛋与更快的 Lua 扩展**：按住右键连续乱画 8 秒会触发经典的「红底三白点」无语彩蛋；Lua 脚本新增原生切窗接口与预编译加速，响应更快（详情见 `docs/api/lua-api.md`）。

### 6. 空格快速预览（QuickLook）支持更多格式 + 内置隐私脱敏反馈
- **Win11 预览修复与新格式直看**：全面修复 Windows 11 资源管理器多标签、桌面和图库下按空格无法预览图片/视频的问题，并新增直接按空格查看 **压缩包（ZIP / TAR / 7Z / RAR）目录内容**、**字体文件（TTF / OTF / WOFF / TTC）样张** 以及 **音视频信息与画面预览**（感谢 GitHub #6 @HedioKojima）。
- **侧边栏左下角一键反馈与隐私自动打码**：点击设置窗左下角「问题反馈」（或「关于 -> 问题反馈」）可导出诊断包或直接提交问题，导出前会在本机自动抹除用户名路径、邮箱、IP、密钥令牌等隐私信息，放心发日志。

## 重要问题修复

- **彻底解决 `Alt + V` 剪贴板历史白屏 / 黑屏问题**：修复冷启动或长时间闲置后唤出剪贴板窗口只剩空白底色、看不到内容的问题，连续呼出瞬开且实时跟随深浅主题。
- **彻底解决管理员模式下打开 Chrome 等浏览器卡死**：修复 Tools3000 以管理员身份运行时，从搜索或手势打开 Chrome 导致窗口无响应的问题，现在以普通权限顺畅启动且不会阻塞软件本身。
- **彻底解决中文及多语言路径下功能/插件消失**：修复软件安装目录或 Windows 用户名包含中文、日文、韩文、俄文、西葡等非英文字符时，部分模块或插件无法正常加载的问题（感谢 Linux.do @sakura_yae）。

## 新功能入口与文件位置速查

为方便你第一时间找到新增或调整了位置的功能，以及备份配置与排查问题，整理如下速查表：

| 功能 / 文件 | 在哪里打开 / 存放在哪里 | 说明 |
| :--- | :--- | :--- |
| **文件占用解锁** | 设置：`系统总控 -> 功能模块`、`效率工具 -> 文件占用解锁`<br>快捷：`托盘右键面板 -> 文件解锁`、`文件右键菜单`、`搜索结果右键` | 可在设置页或托盘一键开关，并支持页内直接选文件检测；关闭或卸载时自动清理右键项 |
| **剪贴板历史开关与数据** | 开关：`托盘右键面板 -> 剪贴板` / `功能模块`<br>安装版数据：`%LOCALAPPDATA%\Tools3000\clipboard\`<br>便携版数据：`<软件目录>\data\clipboard\` | 关机重启不丢的历史数据与图片缓存均保存在此目录，方便备份迁移 |
| **搜索图标 / 实时刷新 / 内存模式** | `效率工具 -> 文件搜索`（图标风格 / 实时监控 / 服务内存管理）<br>搜索窗底部状态栏可直接点击开关「实时监控」 | 开启「Windows 图标」即可同时看到应用、系统命令和浏览器书签的真实原图标 |
| **文件对话框内嵌搜索** | `效率工具 -> 文件对话框助手` | 开启后对 Windows 打开/保存弹窗及 Tools3000 自身弹窗同时生效 |
