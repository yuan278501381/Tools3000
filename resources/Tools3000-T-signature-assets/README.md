# Tools3000 · T 字标方案

本轮重新将 T 纳入核心造型，提供两个结构不同的方向。本目录是供用户评审的设计资产，没有修改产品代码、软件名称或现有图标资源。

- **t-ribbon / 折带 T**：横梁由折叠带状结构形成，斜向竖干延续折面方向，具有前进感。优先推荐这个方向继续评审。
- **t-volume / 立构 T**：横梁与竖干形成一体构件，左右对称；色块辅助表达空间结构。

每版提供彩色SVG母版（`-color.svg`）、小尺寸朱红单色版（`-small.svg`）、浅色背景用深色标志（`-black.svg`）与深色背景用浅色标志（`-white.svg`）。全部由路径构成，无字体依赖、位图、滤镜或外部资源。

为避免折面在托盘和小任务栏中混成细节，32px及以下的彩色导出自动使用纯色轮廓；36px及以上保留折面配色。托盘始终使用单色。此为同一轮廓的尺寸适配，不改变标志形状。

ICO包含16/20/24/30/32/36/40/48/64/128/256像素帧，预览PNG与ICO对应帧逐像素一致。18像素标题栏也有独立导出。

`signature-preview.html`为离线交互预览，`Tools3000-T-signature-assets.zip`包含两版SVG、ICO、大图和概览。窗口及任务栏是模拟，相邻系统图标为简化示意，未声称已在运行中的Tools3000替换图标。

运行`python docs/design/tools3000-t-signature/build_signature.py`可重建。已验证SVG可解析、小尺寸单色、PNG透明度、ICO帧一致性、两个方向切换及1024/736/360宽度布局。
